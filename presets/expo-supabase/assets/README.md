# Assets

Placeholders neutros generados por la Factory (PNG planos). Sustitúyelos por los assets del
proyecto manteniendo nombres y tamaños:

| Archivo | Tamaño | Uso |
|---|---|---|
| `icon.png` | 1024×1024 | Ícono iOS/Android |
| `adaptive-icon.png` | 1024×1024 | Capa frontal del ícono adaptativo Android |
| `splash-icon.png` | 512×512 | Imagen del splash (`resizeMode: contain`) |
| `favicon.png` | 48×48 | Web |
